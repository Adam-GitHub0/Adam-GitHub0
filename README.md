# Adam Mernissi

I am an MSc Cyber Security student at ETH Zürich with interests in applied cryptography, protocol security, distributed systems, and software engineering. My research has covered lattice-based threshold signatures and zero-knowledge proofs, as well as classical attacks on code-based cryptography and HQC.

## Selected work

- [Distributed algorithms in Java](https://github.com/Adam-GitHub0/distributed-algorithms-java) — course implementations of reliable broadcast, per-sender FIFO delivery, and multi-shot lattice agreement over UDP. The repository includes both milestones, source code, and build instructions.
- [sbt contribution](https://github.com/sbt/sbt/pull/7417) — merged upstream work from my Scala Center project, alongside Twirl support for the Metals language server.

I have also worked on network vulnerability assessment with Greenbone/OpenVAS and built a Python ACMEv2 client for certificate issuance. I am interested in turning rigorous security analysis into reliable systems.
